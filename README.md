Було створено схему pandemic та імпортовано CSV-файл у таблицю infectious_cases.

Початкова таблиця містила повторювані атрибути Entity та Code. Для нормалізації до 3НФ ці атрибути були винесені в окрему таблицю countries. У таблицю infectious_cases_normalized було додано поле country_id, яке є зовнішнім ключем до таблиці countries.

Кількість рядків у нормалізованій таблиці infectious_cases_normalized залишилася такою самою, як у початковій таблиці infectious_cases, оскільки кожен запис був перенесений без втрати даних. Таблиця countries містить лише унікальні країни та їх коди.

Для аналізу Number_rabies були розраховані середнє, мінімальне, максимальне значення та сума для кожної країни. Порожні значення були відфільтровані.

Також були створені додаткові колонки: дата першого січня відповідного року, поточна дата та різниця в роках. Додатково створено власну SQL-функцію для розрахунку різниці між поточним роком і роком з таблиці.
